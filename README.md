# V-Menu

A modern restaurant management platform that streamlines operations with digital ordering, kitchen management, and cashier services.

## Overview

V-Menu is a SaaS solution designed to help restaurants modernize their operations. The platform provides an integrated system for order management, kitchen displays, and point-of-sale functionality, all accessible through a responsive web interface.

## Features

- **Real-Time Order Management** - Track and update orders with automatic status synchronization
- **Multi-Tenant Support** - Manage multiple restaurant locations from a single dashboard
- **Kitchen Display System** - Streamlined order flow with prep timers and priority indicators
- **Cashier Mode** - Efficient billing and payment processing
- **Role-Based Access Control** - Secure permissions for owners, kitchen staff, and cashiers
- **Performance Analytics** - Sales trends and staff activity insights

## Tech Stack

- Next.js (React)
- TypeScript
- Tailwind CSS
- Framer Motion (animations)
- Lucide React (icons)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the landing page.
